# 策略中心模块设计文档

## 1. 模块概述

策略中心是InvestMindPro的核心功能模块，提供量化交易策略的管理、分析和信号生成功能。该模块完全依赖LLM进行智能分析，支持预设策略和用户自定义策略，能够根据K线图、技术指标、新闻情绪等多维度数据生成具体的交易操作指令。

### 1.1 核心特性

- **策略数据库存储**：所有策略存储在数据库中，支持动态加载和CRUD操作
- **LLM智能分析**：使用大语言模型进行策略解析和交易信号生成
- **多模态分析**：支持K线图截图的图像识别分析
- **预设策略库**：内置多种经典策略（技术分析、价值投资、机构跟踪、民间战法、AI策略）
- **策略解析**：将用户输入的文字描述转换为标准策略格式
- **交易信号生成**：输出具体的买入/卖出/持有信号及详细操作指令
- **策略标准化**: 统一的JSON格式存储策略配置
- **LLM集成**: 使用大语言模型解析策略文本和生成交易信号
- **K线图分析**: 支持上传或截图K线图进行视觉分析
- **多维度分析**: 综合技术指标、基本面、新闻情绪等
- **规则引擎**: 不依赖LLM的纯规则条件评估
- **仓位管理**: 自动计算建议仓位和止盈止损


功能定位
策略模块是InvestMindPro平台的核心功能之一，提供：
- 预设经典投资策略（格雷厄姆、巴菲特、戴维斯、林奇等）
- 机构持仓跟踪策略（社保基金、QFII、知名游资等）
- 技术分析策略（均线、MACD、KDJ、布林带等）
- 民间交易策略（涨停板、龙头战法、低吸等）
- 用户自定义策略（支持AI解析自然语言描述）
- 基于LLM的智能分析和交易信号生成

### 1.2 设计原则

1. **策略与执行分离**：策略定义存储在数据库，执行逻辑在Python脚本中
2. **模型无默认值**：必须从模型管理模块选择模型，不使用默认模型
3. **标准化格式**：所有策略使用统一的JSON格式存储
4. **可扩展性**：支持添加新的指标类型和策略分类

## 3. 数据模型

### 3.1 策略表 (strategies)

```python
class Strategy(Base):
    __tablename__ = "strategies"
    
    id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False, unique=True)
    description = Column(Text)
    category = Column(String(50))  # technical/fundamental/institutional/folk/ai
    icon = Column(String(10))
    indicators = Column(JSON)       # 指标配置列表
    entry_conditions = Column(JSON) # 入场条件
    exit_conditions = Column(JSON)  # 出场条件
    risk_params = Column(JSON)      # 风险参数
    is_active = Column(Boolean, default=True)
    is_preset = Column(Boolean, default=False)
    created_at = Column(DateTime)
    updated_at = Column(DateTime)
```

### 3.2 交易信号表 (trade_signals)

```python
class TradeSignal(Base):
    __tablename__ = "trade_signals"
    
    id = Column(Integer, primary_key=True)
    strategy_id = Column(Integer, ForeignKey("strategies.id"))
    symbol = Column(String(20))
    signal = Column(String(10))     # BUY/SELL/HOLD
    confidence = Column(Float)
    price = Column(Float)
    stop_loss = Column(Float)
    take_profit = Column(Float)
    quantity_pct = Column(Float)
    analysis = Column(JSON)
    risk_assessment = Column(JSON)
    key_levels = Column(JSON)
    created_at = Column(DateTime)
```

## 6. LLM分析流程

### 6.1 策略文本解析

```
用户输入文本 → LLM解析 → 标准JSON格式 → 存储到数据库
```

**示例输入：**
```
当MACD金叉且RSI小于70时买入，
当MACD死叉或RSI大于80时卖出，
止损5%，止盈15%
```

**解析输出：**
```json
{
    "name": "MACD+RSI组合策略",
    "indicators": [
        {"name": "MACD", "type": "momentum", "params": {...}},
        {"name": "RSI", "type": "oscillator", "params": {"period": 14}}
    ],
    "entry_conditions": [...],
    "exit_conditions": [...],
    "risk_params": {"stop_loss": 0.05, "take_profit": 0.15}
}
```

### 6.2 交易信号生成

```
策略 + 市场数据 + 新闻(可选) + K线图(可选) → LLM分析 → 交易信号
```

**输出格式：**
```json
{
    "signal": "BUY",
    "confidence": 0.85,
    "trade_instruction": {
        "action": "BUY",
        "price": 25.50,
        "quantity_pct": 0.3,

        "take_profit": 29.33,
        "reason": "MACD金叉确认，RSI处于合理区间..."
    },
    "analysis": {
        "technical": "技术面分析...",
        "fundamental": "基本面分析...",
        "sentiment": "市场情绪分析..."
    },
    "risk_assessment": {
```

## 9. 使用流程

### 9.1 使用预设策略

1. 打开策略中心页面
2. 点击"更换策略"打开策略选择器
3. 切换到"预设策略"标签
4. 选择一个策略或点击"导入"保存到我的策略
5. 输入股票代码，加载数据
6. 点击"执行分析"生成交易信号

### 9.2 创建自定义策略

1. 点击"解析策略"按钮
2. 输入策略描述文本
3. 选择分析模型
4. 点击"解析并保存"
5. 策略自动保存到数据库

### 9.3 图像分析

1. 加载股票数据显示K线图
2. 选择策略
3. 点击"截图分析"
4. 系统自动截取K线图并发送给多模态LLM
5. 返回包含图表形态识别的分析结果

核心功能
预设策略库: 14个经典策略，涵盖价值投资、成长投资、技术分析、机构跟踪等
AI策略解析: 用户输入自然语言描述，LLM自动转换为标准格式
智能交易信号: 综合技术指标、基本面、新闻等生成买入/卖出/持有建议
K线图分析: 支持截图或上传K线图进行视觉分析
规则引擎: 不依赖LLM的纯规则条件评估
仓位管理: 自动计算建议仓位和止盈止损价格
