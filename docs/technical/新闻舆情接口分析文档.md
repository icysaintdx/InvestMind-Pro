## 一、概述

本文档详细分析了 InvestMind Pro 项目中所有与新闻、舆情、媒体相关的接口和模块，包括前端组件调用的API、后端API路由、底层数据源接口等。

### 1.1 项目中新闻相关功能模块

| 模块名称 | 功能描述 | 前端组件 | 后端API |
|---------|---------|---------|---------|
| **智能分析** | 个股新闻分析，情绪分析 | 智能分析页面 | `/api/unified-news/stock` |
| **新闻中心** | 统一新闻聚合，多源新闻展示 | `UnifiedNewsView.vue` | `/api/news-center/*` |
| **数据流-新闻流** | 实时新闻流，新闻舆情面板 | `NewsDataPanel.vue` | `/api/news-center/market` |
| **数据流-个股详情** | 个股相关新闻 | 个股详情组件 | `/api/news-center/stock-news/{code}` |

✅ 问题 1：为什么官方文档里没有这个接口？
Tushare 的 news_list 是 「网页端专属接口」，只给官网的新闻页面做数据支撑，Tushare 官方的文档只维护「金融数据类接口」（股票 / 基金 / 期货），这类新闻聚合接口属于边缘功能，所以不写进文档，但接口永久可用，放心调用。
✅ 问题 2：请求返回 code:400 msg:token invalid
解决方案：
检查你的 token 是否复制完整（32 位字符串，无空格）；
Tushare 的 token 区分大小写，复制时不要手动改字符；
确认账号已登录过 Tushare 官网，未登录的 token 会失效。
✅ 问题 3：返回数据为空 / 只有少量新闻
解决方案：
去掉 start_time 和 end_time 空值即可，接口默认返回最新新闻；
不要填太早的时间，该接口只返回 最近 7 天的新闻，超过 7 天的历史新闻无法获取；
page_size 最大只能填 50，超过 50 会被强制改成 50。
