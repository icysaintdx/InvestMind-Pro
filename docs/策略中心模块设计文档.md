# 策略中心模块设计文档

## 1. 模块概述

策略中心是InvestMindPro的核心功能模块，提供智能策略管理与交易信号生成功能。该模块依赖LLM进行策略解析和分析，支持预设策略和用户自定义策略，最终输出具体的交易操作指令。

## 2. 功能特性

### 2.1 策略管理
- **预设策略**: 22个专业策略，涵盖6大类别
- **自定义策略**: 用户可手动创建策略
- **AI解析策略**: 通过LLM将文字描述转换为标准策略格式
- **策略CRUD**: 支持创建、读取、更新、删除操作

### 2.2 K线图分析
- **多周期支持**: 日线、周线、60分钟、30分钟、15分钟
- **技术指标**: MA5/10/20/60、MACD、RSI、BOLL、KDJ
- **实时计算**: 前端计算指标，减少服务器压力
- **交互式图表**: 基于ECharts的专业K线图

### 2.3 信号生成
- **综合分析**: 结合K线、指标、新闻、策略规则
- **模型选择**: 从模型管理加载用户选择的LLM模型
- **交易指令**: 输出买入/卖出/持有信号及具体参数

## 5. API接口

### 5.1 策略管理
- `GET /api/strategy-center/strategies` - 获取策略列表
- `GET /api/strategy-center/strategies/{id}` - 获取策略详情
- `POST /api/strategy-center/strategies` - 创建策略
- `PUT /api/strategy-center/strategies/{id}` - 更新策略
- `DELETE /api/strategy-center/strategies/{id}` - 删除策略

### 5.2 策略解析
- `POST /api/strategy-center/parse` - AI解析策略文本

### 5.3 信号生成
- `POST /api/strategy-center/signal/generate` - 生成交易信号

### 5.4 辅助接口
- `GET /api/strategy-center/categories` - 获取策略分类
- `GET /api/strategy-center/indicators` - 获取可用指标
- `GET /api/strategy-center/stats` - 获取策略统计

## 6. 前端组件

### 6.1 文件结构
```
frontend/src/
├── api/
│   ├── strategyCenter.js    # 策略中心API
│   └── stock.js             # 股票数据API（含指标计算）
└── views/
    └── StrategyCenterView.vue  # 策略中心主视图
```

### 6.2 主要功能
- **策略列表**: 分类筛选、策略卡片展示
- **K线图**: ECharts实现，支持多周期、多指标
- **策略详情**: 指标、入场/出场条件、风险参数
- **信号生成**: 股票代码输入、模型选择、信号结果展示
- **AI解析**: 文本输入、LLM解析、策略创建

## 7. 技术实现

### 7.1 后端
- **框架**: FastAPI
- **策略存储**: 内存存储（可扩展到数据库）
- **策略定义**: 模块化文件结构
  - `backend/api/strategies/technical_strategies.py`
  - `backend/api/strategies/value_strategies.py`
  - `backend/api/strategies/other_strategies.py`
  - `backend/api/strategies/institutional_strategies.py`

### 7.2 前端
- **框架**: Vue 3 + Composition API
- **图表**: ECharts 5
- **指标计算**: 前端JavaScript实现
- **样式**: Scoped CSS + 响应式设计

### 7.3 模型集成
- 从 `/api/config/agents` 加载用户选择的模型
- 支持 DeepSeek、通义千问、GPT-4 等模型
- 模型用于策略解析和信号生成
