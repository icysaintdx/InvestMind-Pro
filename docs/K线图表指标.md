“六脉神剑综合指标” 是金融市场中一类 “多指标共振” 的复合分析工具，核心是融合 6 个经典技术指标的信号，通过 “多维度共识” 判断行情趋势，常见于股票、贵金属等交易场景。
一、核心定义
它并非单一原创指标，而是将 MACD（趋势）、KDJ（超买超卖）、RSI（强弱）、LWR（威廉指标）、BBI（多空均线）、MTM（动量） 这 6 个经典指标的信号进行整合，以 “共振（多个指标同时发出同向信号）” 作为判断依据，简化复杂的技术分析。
二、常见构成与逻辑
不同平台 / 版本的 “六脉神剑” 会略有差异，但核心是6 个指标的协同判断：
组成指标	作用
MACD	判断中期趋势方向（金叉 / 死叉）
KDJ	识别短期超买 / 超卖及拐点
RSI	衡量价格波动的强弱程度
LWR	反映价格在近期区间的相对位置
BBI	综合多周期均线，判断多空趋势
MTM	衡量价格变化的速度（动量）
三、使用方法（以主流版本为例）
买入信号：6 个指标同时发出 “多头信号”（如 MACD 金叉、KDJ 金叉、RSI>50 等），通常显示为 “全绿 / 全红箭头”；
卖出信号：6 个指标同时发出 “空头信号”（如 MACD 死叉、KDJ 死叉、RSI<50 等）；
简化口诀：“六绿 / 红考虑多 / 空，三红 / 绿就下车”（部分平台的可视化规则）。
四、特点
优势：通过多指标共振降低单一指标的 “骗线” 风险，适合技术小白快速上手；
局限：信号相对滞后（需等 6 个指标同步），震荡行情中可能频繁出现无效信号，需结合量能、趋势等辅助判断。

## 三、【项目开发必备 - 核心指标计算公式合集】（所有指标的数学公式，可直接转代码，无手写误差，Python/Java/JS通用）

### ✔️ 均线类
- MA5 = (收盘价1+收盘价2+收盘价3+收盘价4+收盘价5) / 5
- MA10 = 最近10日收盘价的算术平均值
### ✔️ MACD指标 (参数12,26,9)
- EMA12 = 2/(12+1)*当日收盘价 + 11/(12+1)*前日EMA12
- EMA26 = 2/(26+1)*当日收盘价 + 25/(26+1)*前日EMA26
- DIF = EMA12 - EMA26
- DEA = 2/(9+1)*当日DIF + 8/(9+1)*前日DEA
- MACD柱 = (DIF - DEA) * 2
### ✔️ KDJ指标 (参数9,3,3)
- RSV = (当日收盘价 - 9日最低价) / (9日最高价 - 9日最低价) * 100
- K = 2/3*前日K + 1/3*当日RSV
- D = 2/3*前日D + 1/3*当日K
- J = 3*K - 2*D
### ✔️ RSI指标 (参数6,12)
- RSI6 = (6日内上涨幅度之和) / (6日内上涨幅度之和+6日内下跌幅度之和) * 100
### ✔️ LWR指标 (参数9,3,3)
- RSV = (9日最高价 - 当日收盘价) / (9日最高价 - 9日最低价) * 100
- LWR1 = SMA(RSV,3,1)
- LWR2 = SMA(LWR1,3,1)
### ✔️ MTM+MTMMA指标 (参数6,8)
- MTM = 当日收盘价 - 6日前收盘价
- MTMMA = MTM的8日算术平均值
### ✔️ K线形态核心计算
- 阳线实体 = 收盘价 - 开盘价
- 阴线实体 = 开盘价 - 收盘价
- 上影线 = 最高价 - max(开盘价,收盘价)
- 下影线 = min(开盘价,收盘价) - 最低价

#### 规则1：【金额阈值筛选】—— 最核心、最简单的规则（必做）
A股1手=100股，机构的单笔成交，**绝对不会是几百、几千块的小单**，行业统一的机构单标准：
- 小盘股（股价＜20元，流通市值＜50亿）：单笔成交金额 ≥ **100万元** → 判定为「机构大单」；

#### 规则2：【成交手法筛选】—— 排除游资，精准锁定机构（必做）
机构交易的核心特征：**稳健、持续、分批、不撤单**，和游资的「暴力扫货、快速撤单、一日游」完全不同，2个关键特征：

- 机构**真买入**：连续出现机构买单 → 成交量持续放大 + 股价稳步上涨（小阳线推升，不是涨停板暴力拉升）；
- 机构**真卖出**：连续出现机构卖单 → 成交量持续放大 + 股价稳步下跌（小阴线下跌，不是跌停板暴跌）；
> 反例：如果只有1笔大单买入，股价瞬间拉升后马上回落，成交量也萎缩，这就是「主力诱多的假大单」，不是真机构入场。

def get_stock_kline(stock_code, period="day", count=60):

def identify_large_order(trade_df, threshold=LARGE_ORDER_THRESHOLD):
    """
    识别机构大单
    :param trade_df: 逐笔成交DataFrame
    :param threshold: 大单金额阈值
    :return: 大单统计结果 {"buy": 买入大单数量, "sell": 卖出大单数量, "buy_amount": 买入总额, "sell_amount": 卖出总额}
    """
    if trade_df.empty:
        return {"buy": 0, "sell": 0, "buy_amount": 0, "sell_amount": 0}
    
    # 筛选大单（金额≥阈值 + 主动成交）
    large_buy = trade_df[(trade_df["amount"] >= threshold) & (trade_df["direction"] == "buy")]
    large_sell = trade_df[(trade_df["amount"] >= threshold) & (trade_df["direction"] == "sell")]
    
    return {
        "buy": len(large_buy),
        "sell": len(large_sell),
        "buy_amount": large_buy["amount"].sum(),
        "sell_amount": large_sell["amount"].sum()
    }

# ===================== 3. 六脉神剑指标计算函数 =====================
def calculate_six_pulse(df):
    """计算六脉神剑六大指标"""
    if len(df) < max(MA10_PERIOD, MACD_SLOW, KDJ_PERIOD, RSI_PERIOD, LWR_PERIOD, MTMMA_PERIOD):
        return df
    
    # 1. 均线（MA5/MA10）
    df["ma5"] = df["close"].rolling(window=MA5_PERIOD).mean()
    df["ma10"] = df["close"].rolling(window=MA10_PERIOD).mean()
    df["ma_gold"] = (df["ma5"] > df["ma10"]) & (df["ma5"].shift(1) <= df["ma10"].shift(1))  # 金叉
    
    # 2. MACD
    df["ema12"] = df["close"].ewm(span=MACD_FAST, adjust=False).mean()
    df["ema26"] = df["close"].ewm(span=MACD_SLOW, adjust=False).mean()
    df["dif"] = df["ema12"] - df["ema26"]
    df["dea"] = df["dif"].ewm(span=MACD_SIGNAL, adjust=False).mean()
    df["macd"] = 2 * (df["dif"] - df["dea"])
    df["macd_gold"] = (df["dif"] > df["dea"]) & (df["dif"].shift(1) <= df["dea"].shift(1))  # 金叉
    
    # 3. KDJ
    low_min = df["low"].rolling(window=KDJ_PERIOD).min()
    high_max = df["high"].rolling(window=KDJ_PERIOD).max()
    df["rsv"] = (df["close"] - low_min) / (high_max - low_min) * 100
    df["k"] = df["rsv"].ewm(span=3, adjust=False).mean()
    df["d"] = df["k"].ewm(span=3, adjust=False).mean()
    df["j"] = 3 * df["k"] - 2 * df["d"]
    df["kdj_gold"] = (df["k"] > df["d"]) & (df["k"].shift(1) <= df["d"].shift(1))  # 金叉
    
    # 4. RSI
    delta = df["close"].diff(1)
    gain = delta.where(delta > 0, 0)
    loss = -delta.where(delta < 0, 0)
    avg_gain = gain.rolling(window=RSI_PERIOD).mean()
    avg_loss = loss.rolling(window=RSI_PERIOD).mean()
    rs = avg_gain / avg_loss
    df["rsi"] = 100 - (100 / (1 + rs))
    df["rsi_bull"] = df["rsi"] > 50  # 多头区域
    
    # 5. LWR
    df["lwr_rsv"] = (high_max - df["close"]) / (high_max - low_min) * 100
    df["lwr1"] = df["lwr_rsv"].ewm(span=3, adjust=False).mean()
    df["lwr2"] = df["lwr1"].ewm(span=3, adjust=False).mean()
    df["lwr_gold"] = (df["lwr1"] > df["lwr2"]) & (df["lwr1"].shift(1) <= df["lwr2"].shift(1))  # 金叉
    
    # 6. MTM+MTMMA
    df["mtm"] = df["close"] - df["close"].shift(MTM_PERIOD)
    df["mtmma"] = df["mtm"].rolling(window=MTMMA_PERIOD).mean()
    df["mtm_gold"] = (df["mtm"] > df["mtmma"]) & (df["mtm"].shift(1) <= df["mtmma"].shift(1))  # 金叉
    
    # 六脉神剑多头共振信号（至少满足4个金叉/多头条件）
    df["six_pulse_bull"] = (
        df["ma_gold"].astype(int) + df["macd_gold"].astype(int) + df["kdj_gold"].astype(int) +
        df["rsi_bull"].astype(int) + df["lwr_gold"].astype(int) + df["mtm_gold"].astype(int)
    ) >= 4
    
    return df

    机构大单 + 六脉神剑 共振判断
    :param large_order: 机构大单统计结果
    :param six_pulse_df: 含六脉神剑指标的K线数据

    """

    order_bull = large_order["buy_amount"] > large_order["sell_amount"] and large_order["buy"] >= 2
    order_bear = large_order["sell_amount"] > large_order["buy_amount"] and large_order["sell"] >= 2
    
    # 六脉神剑多头信号
    pulse_bull = latest_kline["six_pulse_bull"]
    
    # 共振信号
    if order_bull and pulse_bull:
        return 1, "买入信号：机构大单入场 + 六脉神剑多头共振"
    elif order_bear and not pulse_bull:
        return -1, "卖出信号：机构大单离场 + 六脉神剑空头"
    else:
        return 0, "观望信号：无明确共振"

## 三、代码说明
1. **数据层**
   - `get_stock_kline`：从东方财富接口获取日线/分钟线 K 线数据，用于计算六脉神剑指标。
   - `get_realtime_trade`：获取实时逐笔成交明细，包含价格、成交量、成交方向、金额。

2. **机构大单识别**
   - 核心规则：**主动成交 + 单笔金额≥阈值**，区分买入/卖出大单，统计数量和总额。
   - 阈值可根据股票市值调整（小盘股 100 万、中盘股 300 万、大盘股 500 万）。

3. **六脉神剑指标**
   - 整合 **MA、MACD、KDJ、RSI、LWR、MTM** 六大指标，计算金叉/多头状态。
   - 多头共振条件：**至少4个指标满足多头信号**。

4. **信号共振**
   - 买入信号：机构买入大单占优 + 六脉神剑多头共振。
   - 卖出信号：机构卖出大单占优 + 六脉神剑空头。
   - 观望信号：无明确共振。

## 四、运行注意事项
1. 免费接口有频率限制，建议将 `time.sleep(5)` 调整为 10 秒以上，避免被封 IP。
2. 股票代码格式：上证股票后缀 `.sh`（如 600519.sh），深证股票后缀 `.sz`（如 000001.sz）。
3. 若需对接券商付费接口，替换 `get_stock_kline` 和 `get_realtime_trade` 函数即可。
