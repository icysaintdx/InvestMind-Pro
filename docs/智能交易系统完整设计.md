# 智能交易系统完整设计文档

## 一、系统概述

### 1.1 系统目标
构建一个完整的策略+AI智能交易系统，支持：
- 策略回测与优化
- 实时行情监控
- 智能信号生成
- 虚拟/模拟交易
- 持仓管理与风控

### 1.2 核心特性
- **双引擎架构**：规则引擎（快速确定性）+ LLM引擎（智能分析）
- **中国股市适配**：T+1交易规则、涨跌停限制、交易时间管理
- **实时数据接入**：支持多数据源（AKShare、Tushare、通达信等）
- **完整交易闭环**：从信号生成到交易执行到持仓管理

### 5.2 T+1处理流程
```
┌─────────────────────────────────────────────────────────────────┐
│                      T+1处理流程                                 │
└─────────────────────────────────────────────────────────────────┘

【买入时】
1. 执行买入订单
2. 增加持仓数量
3. 创建冻结记录（frozen_quantity = 买入数量）
4. 设置解冻日期 = 下一个交易日

【每日开盘前】
1. 检查所有冻结记录
2. 如果当前日期 >= 解冻日期：
   - available_quantity += frozen_quantity
   - frozen_quantity = 0
   - 删除冻结记录

【卖出时】
1. 检查 available_quantity >= 卖出数量
2. 如果不足，拒绝卖出
3. 如果足够，执行卖出
4. 更新 available_quantity
```

### 5.3 风控检查流程
```python
class RiskManager:
    """风险管理器"""
    
    def __init__(self):
        self.config = {
            "max_single_position": 0.30,  # 单只股票最大仓位30%
            "max_total_position": 0.80,   # 总仓位最大80%
            "max_daily_loss": 0.05,       # 单日最大亏损5%
            "max_single_loss": 0.10,      # 单只股票最大亏损10%
            "min_cash_reserve": 0.10,     # 最小现金储备10%
        }
    
    def check_buy_risk(self, stock_code: str, quantity: int, price: float) -> RiskCheckResult:
        """买入风控检查"""
        checks = [
            self._check_single_position_limit(stock_code, quantity, price),
            self._check_total_position_limit(quantity, price),
            self._check_cash_reserve(quantity, price),
            self._check_price_limit(stock_code, price),  # 涨停不买
            self._check_daily_loss_limit(),
        ]
        return self._aggregate_results(checks)
    
    def check_sell_risk(self, stock_code: str, quantity: int) -> RiskCheckResult:
        """卖出风控检查"""
        checks = [
            self._check_t_plus_1(stock_code, quantity),
            self._check_available_quantity(stock_code, quantity),
            self._check_price_limit(stock_code),  # 跌停不卖（可选）
        ]
        return self._aggregate_results(checks)
```
