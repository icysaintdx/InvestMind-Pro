# 策略模块完整设计文档

> 本文档整合了策略中心的所有设计内容，是策略模块的唯一权威文档。

## 1. 模块概述

### 1.1 核心理念

策略中心是InvestMindPro的核心功能模块，其核心设计理念是：

**策略 = 数据库中的计算公式**

策略本身只是存储在数据库中的规则定义（JSON格式），真正的执行需要：
1. **策略解析引擎** - 读取策略公式
2. **数据获取** - 获取K线和指标数据
3. **条件评估** - 根据策略公式计算是否满足条件
4. **信号生成** - 输出买卖点和交易建议

### 1.2 双引擎架构

系统支持两种分析引擎，可以**手动选择**或**自动降级**：

### 3.2 条件运算符

规则引擎支持以下运算符：

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `>` | 大于 | `RSI > 70` |
| `<` | 小于 | `RSI < 30` |
| `>=` | 大于等于 | `ADX >= 25` |
| `<=` | 小于等于 | `ADX <= 20` |
| `==` | 等于 | `signal == 1` |
| `cross_above` | 上穿（金叉） | `MA5 cross_above MA10` |

### 4.2 条件评估逻辑

**入场条件**：所有条件都满足才触发买入信号
```python
def evaluate_entry_conditions(self, df, idx, strategy):
    entry_conditions = strategy.get('entry_conditions', [])
    met_conditions = []
    
    for cond in entry_conditions:
        result = self.evaluate_condition(df, idx, cond)
        if result:
            met_conditions.append(cond['description'])
    
    # 所有条件都满足才返回True
    all_met = len(met_conditions) == len(entry_conditions)
    confidence = len(met_conditions) / len(entry_conditions)
    
    return all_met, met_conditions, confidence
```

**出场条件**：任一条件满足即触发卖出信号
```python
def evaluate_exit_conditions(self, df, idx, strategy):
    exit_conditions = strategy.get('exit_conditions', [])
    met_conditions = []
    
    for cond in exit_conditions:
        result = self.evaluate_condition(df, idx, cond)
        if result:
            met_conditions.append(cond['description'])
    
    # 任一条件满足即返回True
    any_met = len(met_conditions) > 0
    
    return any_met, met_conditions
```

### 4.3 交叉判断

```python
def check_cross_above(self, df, idx, indicator1, indicator2):
    """检查上穿条件（金叉）"""
    if idx < 1:
        return False
    
    # 当前值
    val1_curr = self.get_indicator_value(df, idx, indicator1)
    val2_curr = self.get_indicator_value(df, idx, indicator2)
    
    # 前一根K线的值
    val1_prev = self.get_indicator_value(df, idx - 1, indicator1)
    val2_prev = self.get_indicator_value(df, idx - 1, indicator2)
    
    # 上穿：前一根在下方或相等，当前在上方
    return val1_prev <= val2_prev and val1_curr > val2_curr
```

## 9. 注意事项

1. **策略只是公式** - 策略本身不执行任何操作，需要引擎来解析和执行
2. **双引擎互补** - 规则引擎用于快速确定性分析，LLM用于智能深度分析
3. **自动降级** - 当LLM不可用时，系统自动使用规则引擎
4. **数据依赖** - 分析质量取决于K线数据的完整性和准确性
5. **风险提示** - 所有交易信号仅供参考，不构成投资建议
