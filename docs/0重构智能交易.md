智能交易系统重构设计方案
一、问题分析
当前架构的问题：

AutoTradeView 孤立 - 没有K线、没有策略详情，用户体验割裂
功能重复 - 策略中心、智能交易、自动交易三个页面功能重叠
数据流分散 - 交易日志、订单分布在多个地方

五、数据结构设计
5.1 交易计划 (TradingPlan)
python
复制
class TradingPlan:
    plan_id: str              # 计划ID
    plan_name: str            # 计划名称 (如: "贵州茅台-MACD交叉")
    
    # 策略信息
    strategy_id: str
    strategy_name: str
    strategy_config: Dict     # 策略参数
    
    # 标的信息
    stock_code: str
    stock_name: str
    
    # 资金参数
    allocated_capital: float  # 分配资金
    max_position_ratio: float # 最大仓位比例
    
    # 风控参数
    stop_loss_pct: float      # 止损比例
    take_profit_pct: float    # 止盈比例
    trailing_stop: bool       # 是否移动止损
    
    # 执行参数
    check_interval: int       # 检查间隔(秒)
    decision_mode: str        # rule_only | rule_ai | ai_only
    
    # 状态
    status: str               # pending | running | paused | stopped
    created_at: datetime
    started_at: datetime
    
    # 统计
    signals_count: int        # 信号数量
    trades_count: int         # 成交数量
    total_pnl: float          # 累计盈亏
    total_pnl_pct: float      # 累计盈亏率
5.2 交易日志 (TradeLog)
python
复制
class TradeLog:
    log_id: str
    timestamp: datetime
    log_type: str             # signal | order | execution | risk | system
    
    # 来源
    source: str               # manual | auto
    plan_id: Optional[str]    # 关联的交易计划
    strategy_name: Optional[str]
    
    # 标的
    stock_code: str
    stock_name: str
    
    # 内容
    action: str               # buy_signal | sell_signal | buy | sell | stop_loss | take_profit
    message: str              # 详细描述
    
    # 交易详情 (如果是订单)
    direction: Optional[str]  # buy | sell
    quantity: Optional[int]
    price: Optional[float]
    amount: Optional[float]
    
    # 信号详情 (如果是信号)
    confidence: Optional[float]
    conditions_met: Optional[List[str]]
