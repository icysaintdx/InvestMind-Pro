# 策略规则引擎设计文档

## 概述

本文档描述了一个完整的**策略驱动交易系统**，它可以：

1. **纯脚本规则引擎** - 根据策略条件自动判断买卖点，不依赖LLM
2. **历史回测** - 在历史K线数据上测试策略，找出所有交易点
3. **实时信号监控** - 接入实时行情，等待交易机会
4. **虚拟交易对接** - 自动执行买卖操作

## 核心组件

### 1. 策略规则引擎 (strategy_rule_engine.py)

这是系统的核心，**纯Python脚本实现**，不依赖任何LLM。

#### 1.1 指标计算器 (IndicatorCalculator)

支持的技术指标：
- **MA** - 简单移动平均线
- **EMA** - 指数移动平均线
- **RSI** - 相对强弱指数
- **MACD** - 移动平均收敛散度
- **BOLL** - 布林带
- **ADX** - 平均趋向指数
- **KDJ** - 随机指标
- **Volume MA** - 成交量均线

#### 1.2 条件评估器

支持的运算符：
- `>`, `<`, `>=`, `<=`, `==` - 数值比较
- `cross_above` - 上穿（金叉）
- `cross_below` - 下穿（死叉）

#### 1.3 信号生成器

根据策略条件生成交易信号：
- **BUY** - 买入信号（所有入场条件满足）
- **SELL** - 卖出信号（任一出场条件满足）
- **HOLD** - 持有/观望

## 使用流程

### 1. 历史回测（测试策略）

```
用户选择策略 → 选择股票 → 设置回测参数 → 执行回测
                                              ↓
                                        规则引擎分析K线
                                              ↓
                                        找出所有买卖点
                                              ↓
                                        计算收益统计
                                              ↓
                                        返回回测结果
```

### 2. 实时交易（智能交易）

```
用户选择策略 → 选择股票 → 启动监控
                              ↓
                        定时获取实时行情
                              ↓
                        规则引擎分析当前状态
                              ↓
                    ┌─────────┴─────────┐
                    ↓                   ↓
              满足入场条件          满足出场条件
                    ↓                   ↓
              生成买入信号          生成卖出信号
                    ↓                   ↓
              执行虚拟买入          执行虚拟卖出
```

## 规则引擎 vs LLM

| 特性 | 规则引擎 | LLM分析 |
|------|---------|---------|
| 速度 | 毫秒级 | 秒级 |
| 成本 | 免费 | 需要API费用 |
| 一致性 | 100%确定性 | 有随机性 |
| 灵活性 | 固定规则 | 可理解自然语言 |
| 适用场景 | 量化回测、自动交易 | 复杂分析、策略解读 |

**推荐使用方式：**
- **回测和自动交易** → 使用规则引擎（快速、稳定、免费）
- **策略解读和深度分析** → 使用LLM（智能、灵活）
