# 策略模块架构设计 v2.0

## 1. 核心设计理念

### 1.1 问题分析
当前设计的问题：
- ❌ 策略硬编码在Python脚本中，无法动态增删改
- ❌ 前端添加/修改策略无法同步到后端
- ❌ K线图功能不完善，缺少专业交易标注
- ❌ 没有真正实现策略执行引擎

### 1.2 正确的架构
```
┌─────────────────────────────────────────────────────────────────┐
│                        策略中心架构                              │
├─────────────────────────────────────────────────────────────────┤
```

### 3.4 信号生成器
```python
class SignalGenerator:
    """信号生成器 - 综合各引擎输出生成交易信号"""
    
    def generate_signal(self, strategy, kline_data, use_llm=True, use_image=False):
        """生成交易信号"""
        # 1. 计算指标
        indicators = self.indicator_engine.calculate(kline_data, strategy.indicators)
        
        # 2. 评估规则
        rule_result = self.rule_engine.evaluate(strategy.rules, indicators)
        
        # 3. LLM分析（可选）
        if use_llm:
            llm_result = self.llm_engine.analyze(strategy, indicators)
        
        # 4. 图像分析（可选）
        if use_image:
            chart_image = self.capture_chart()
            image_result = self.llm_engine.analyze_with_image(strategy, chart_image)
        
        # 5. 综合生成信号
        return self.combine_signals(rule_result, llm_result, image_result)
```

## 5. 数据库表设计

### 5.1 strategies 表
```sql
CREATE TABLE strategies (
    id UUID PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    category VARCHAR(50),
    source VARCHAR(20) DEFAULT 'user',
    icon VARCHAR(10),
    is_active BOOLEAN DEFAULT true,
    version VARCHAR(10) DEFAULT '1.0',
    created_by UUID,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 5.2 strategy_indicators 表
```sql
CREATE TABLE strategy_indicators (
    id UUID PRIMARY KEY,
    strategy_id UUID REFERENCES strategies(id),
    name VARCHAR(50) NOT NULL,
    type VARCHAR(30),
    params JSONB,
    weight DECIMAL(3,2),
    description TEXT,
    sort_order INT
);
```

### 5.3 strategy_rules 表
```sql
CREATE TABLE strategy_rules (
    id UUID PRIMARY KEY,
    strategy_id UUID REFERENCES strategies(id),
    rule_type VARCHAR(20),  -- entry/exit
    name VARCHAR(100),
    logic VARCHAR(10),  -- AND/OR
    conditions JSONB,
    weight DECIMAL(3,2),
    priority INT,
    description TEXT
);
```

### 5.4 strategy_risk_params 表
```sql
CREATE TABLE strategy_risk_params (

    trailing_step DECIMAL(5,2),

    take_profit_value DECIMAL(10,4),
```

### 5.5 strategy_prompts 表
```sql
CREATE TABLE strategy_prompts (
```

## 7. 工作流程

### 7.1 策略创建流程
```
用户输入策略描述
       │
       ▼
LLM解析提取关键信息
       │
       ▼
生成标准策略结构
       │
       ▼
用户确认/修改
       │
       ▼
保存到数据库
```

### 7.2 信号生成流程
```
选择策略 + 输入股票代码
           │
           ▼
    获取K线数据
           │
           ▼
    计算技术指标
           │
           ▼
┌──────────┴──────────┐
│                     │
▼                     ▼
规则引擎评估      LLM智能分析
│                     │
└──────────┬──────────┘
           │
           ▼
    综合生成信号
           │
           ▼
    输出交易建议
```

### 7.3 图像分析流程
```
生成K线图截图（含指标和标注）
              │
              ▼
      发送给多模态LLM
              │
              ▼
      LLM识别图表特征
              │
              ▼
      结合策略规则分析
              │
              ▼
      输出交易建议
```
