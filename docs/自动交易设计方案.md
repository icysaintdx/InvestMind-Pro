一、现状分析
当前系统能力
模块	现有功能	缺失功能
策略中心	✅ 策略定义、✅ 规则引擎、✅ 回测	❌ 自动监控、❌ 自动执行
模拟交易	✅ 手动买卖、✅ 持仓管理、✅ K线展示	❌ 策略绑定、❌ 自动交易
实时监控	✅ RealtimeMonitorPanel组件	❌ 策略驱动监控、❌ 信号自动执行
核心问题
策略与交易断层 - 策略中心生成信号后，需要人工复制到模拟交易执行
缺少持续监控服务 - 没有后台服务持续获取行情并评估策略
缺少自动执行机制 - 信号生成后没有自动下单逻辑

def is_trading_time() -> bool:
    now = datetime.now()
    # 周末不交易
    if now.weekday() >= 5:
        return False
    # 交易时段
    morning = time(9, 30) <= now.time() <= time(11, 30)
    afternoon = time(13, 0) <= now.time() <= time(15, 0)
    return morning or afternoon
