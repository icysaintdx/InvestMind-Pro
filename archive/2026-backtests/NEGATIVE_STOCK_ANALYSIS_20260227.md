### 方案二：增加过滤条件

#### 添加波动率过滤

```python
def volatility_filter(df, min_atr_pct=0.02):
    """
    只交易波动率足够大的股票
    min_atr_pct: ATR/收盘价的最小比例 (2%)
    """
    atr = ta.atr(df['high'], df['low'], df['close'], length=14)
    atr_pct = atr / df['close']
    return atr_pct > min_atr_pct
```

**应用**:
- 工商银行ATR%长期<1.5% → 跳过交易
- 伊利股份波动期ATR%>2.5% → 正常交易

### 方案三：改用混合策略

#### 价值+趋势混合策略
对于低波动蓝筹股，改用更长期的价值投资策略：

```python
class ValueTrendStrategy:
    def __init__(self):
        self.pe_threshold = 15  # PE低于15才考虑
        self.pb_threshold = 2.0  # PB低于2才考虑
        
    def should_trade(self, stock_data, fundamentals):
        # 基本面过滤
        if fundamentals['pe'] > self.pe_threshold:
            return False
        if fundamentals['pb'] > self.pb_threshold:
            return False
        # 趋势确认
        return super().should_trade(stock_data)
```

**适用股票**: 工商银行、中国平安、伊利股份等价值蓝筹
